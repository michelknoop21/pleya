# Glossary

| Term | What it means |
|---|---|
| **Plex / Jellyfin** | Software that runs your own streaming service at home. Pleya is the app that connects to it. |
| **Server** | The computer or NAS running Plex or Jellyfin, where the media lives |
| **Library** | A collection on the server, such as Films or Shows |
| **Hub / row** | A horizontal row of titles on the home screen |
| **Billboard / hero** | The large featured item at the top of Home |
| **Profile** | One person's space, with their own history and lists |
| **Plex Home** | The Plex feature for household accounts. Those users become profiles here. |
| **Quick Connect** | A Jellyfin sign-in method using a code instead of a password |
| **Continue watching** | The row of everything you started and did not finish |
| **Match %** | A title's rating expressed as a percentage |
| **Direct play** | The server sends the file untouched, doing no work |
| **Transcoding** | The server converts the file on the fly to something the device can take |
| **Version** | One of several qualities of the same title on the server, for example 4K and 1080p |
| **OLED theme** | The pure black theme, easier on an OLED panel |
| **Picture in Picture** | Playback continues in a small floating window |
| **Sleep timer** | Stops playback after a set time |
| **Sync rule** | A standing download agreement for a show, such as three unwatched episodes ready |
| **DVR** | Recording live television through the server |
| **EPG / Guide** | The electronic programme guide for Live TV |
| **Watch Together** | Synchronised playback with other people, over a session code |
| **Pleya Share** | One device serving its local folders to your other Pleya devices |
| **Companion Remote** | Your phone driving the app on a TV or computer |
| **Requests** | Asking for a title through Jellyseerr or Overseerr |
| **Watchlist** | One list built from your Plex watchlist and your Jellyfin favourites |
| **My Pleya** | The personal tab on a phone that holds your watchlist, downloads, requests and settings |
| **Trakt / MAL / AniList / Simkl** | External services that track what you watched |
| **Passthrough** | Sending compressed audio to a receiver instead of decoding it on the device |
| **Wi-Fi Aware** | A direct device-to-device link with no router or hotspot involved |
