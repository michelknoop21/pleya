Wat de server hier beheert

De roots komen uit de mounts van de container (PLEYA_SERVER_MEDIA_DIRS) en zijn hier alleen te kiezen, niet te typen. Mounts toevoegen gebeurt in Docker of op de host; Pleya schrijft nooit in een mediamap en verwacht de mounts :ro.

Inodevertrouwen

Per root gemeten bij elke scanronde. Op een root zonder betrouwbare inodes (ntfs, sommige netwerkmounts) herkent de scanner een hernoemd bestand via de signatuur. De meting wordt getoond en nooit stilzwijgend gepromoveerd; overrulen kan met PLEYA_SERVER_INODE_TRUST.
