Integriteit

Elk bestand komt met een SHA-256 van precies de bytes die je krijgt. Hervatten na een verbroken verbinding mag alleen als die digest nog gelijk is; verving de server het bestand, dan begint de download opnieuw in plaats van dat je een half oud en half nieuw bestand overhoudt.
