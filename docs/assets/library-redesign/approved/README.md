# Goedgekeurde bibliotheekrichting

Ongewijzigde kopieën uit de door Michel beoordeelde lokale ontwerpcollectie
`collections-playlists/` (cn08 voorstel 1 en selected-style-followup).
`sintel-selected.png` en `charge-selected.png` komen uit dynamic-density-preview;
Michels latere uniforme achtergrondblur geldt ook voor de overige vensters.
De oudere scherpe achtergronden zijn alleen compositiereferentie.

Deze ontwerpen zijn geen runtime-, server- of hardwarebewijs. De bestaande
native shell, bronautoriteit en platformbediening blijven leidend. De opdracht
en reconstructiemap staan in `../../../library-redesign-implementation.md`;
de itemstatus blijft in VIS-COL-PLAY1 van het bestaande tvOS-register.
